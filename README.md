# 🗳️ PollStream

**PollStream** is a real-time polling application built with Go and WebSockets. Designed with Clean Architecture for high performance and maintainability.

---

## ✨ Features
- **Real-time**: Instant vote updates via WebSockets.
- **Dynamic**: Create polls with custom questions and multiple options.
- **Responsive**: Modern glassmorphic UI built with vanilla technologies.

---

## 🛠️ Tech Stack
- **Backend**: Go, Gorilla WebSockets, PostgreSQL.
- **Frontend**: Vanilla HTML5, CSS3, JavaScript.
